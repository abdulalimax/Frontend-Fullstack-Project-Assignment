# BloodPulse — Emergency Blood Donation Platform 🩸

## Overview
BloodPulse holo ekti enterprise-grade, responsive fullstack web platform ja emergency blood request ebong real-time donor connection manage kore. Eti Next.js App Router architecture-e Server ebong Client component-er balance bojay rekhe toiri kora hoyeche, ja high performance, secure route handling ebong smooth user experience nishchit kore.

## Core Capabilities
- **Role-Based Architecture:** Admin, Recipient/User, ebong Donor/Provider—ei 3 ti distinct role-er jonno dynamic navigation ebong Next.js Middleware route security.
- **One-Click Demo Authentication:** Login page-e shorashori 1-click demo button-er maddhome proti role-er access verification.
- **Stripe Checkout Pipeline:** Emergency operational verification fee process korar jonno official Stripe test gateway ebong dedicated success ledger flow.
- **Data Integrity & Validation:** React Hook Form ebong Zod schema diye instant real-time client-side error handling.
- **Data Visualization & Analytics:** Admin dashboard-e Recharts diye donor availability ebong emergency distribution metrics tracking.
- **Mobile-First UX:** Tailwind CSS ebong shadcn/ui babohar kore fully responsive, accessible ebong consistent UI design system.

## Tech Stack
Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, Zod, React Hook Form, Stripe, Recharts, Sonner.
